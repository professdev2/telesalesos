# TelesalesOS — Training / Academy mockup variations

Four screens on the app shell (new logo, playbook nav, Training active), self-contained HTML + full-page PNG at 1600 px.

| File | Persona | What it shows |
|---|---|---|
| T1-academy-home-catalog | Agent (Kayla Brooks) | Training home: progress stats, resume card, learning paths, course library with Required / Certification badges, due-this-week rail, certifications, activity heatmap, pod completion |
| T2-learning-path-gated-onboarding | Agent | 14-day onboarding path: five phases, each with lessons and a gate (quiz ≥ 80%, roleplay scores, manager sign-off); readiness ring tied to Recruiting → Readiness; coach notes; cohort |
| T3-lesson-player-quiz-roleplay | Agent | Lesson player: video with chapter markers, transcript with highlighted script line, knowledge check, "Practice this objection" AI roleplay launch, resources, notes, script token preview |
| T4-manager-training-dashboard | Sales Manager (Marcus Reyes) | Team view: completion / overdue / roleplay / certs per agent, roleplay score distribution with a suggested assignment, course effectiveness (QA lift), assign-course form with a queue gate, sign-offs waiting, certs expiring |

Open `index.html` for links. Assets (CSS + fonts) are in `assets/`.
